## Who I Am

Backend engineer with a platform mindset. I work primarily in **Node.js / TypeScript**, and I think about systems the way an operator would — not just "does it work" but "will it hold up at 3am when load spikes and someone's paging you."

My projects reflect that: a self-hosted log ingestion platform with auto-scaling K8s pods, a booking API with atomic seat transactions and rate-limited auth routes, and an AI document pipeline with async BullMQ workers and distributed caching.

Based in **Ahmedabad, India** · Open to backend, platform, and cloud engineering roles · Remote-friendly

## Engineering Principles

```
Layered architecture     →  Controllers own HTTP. Services own logic. Never mixed.
Observability first      →  Structured logs, health endpoints, metrics from day one.
Config over hardcoding   →  Env vars, K8s ConfigMaps/Secrets. Credentials never in code.
Document as you build    →  Swagger specs, .env.example, and architecture diagrams ship with the code.
Fail gracefully          →  Error boundaries, retry logic, and circuit breakers where load demands it.
```
